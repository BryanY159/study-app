# Plan and record: release v2.3.1 (drill setup: source and filter)

Status: **built, `v2.3.1` prepared locally, not tagged or pushed.** Starting point: `main` at `76328a8`
(v2.3.0 plus the CI diagnostics). v2.3.0 was tagged but its CI run failed at e2e, so it was never deployed;
v2.3.1 is the release that goes out.

## What changed
Drill setup used one list of filters with "Study bank only" among them, so the bank could not be combined
with "not seen yet" or "previously missed". It now has two separate choices, using the same radio rows,
card and spacing as before:

- **Questions from:** "All questions" / "Study bank only". Shown only when the pack has study-bank questions.
- **Which ones:** "All" / "Not seen yet" / "Previously missed". Every option shows its count for the current
  source and topic selection (and the "hide flagged" setting).
- The **Start** button states the total: "Start drill · 167 study bank not seen yet", "Start drill · 12 study
  bank previously missed", "Start drill · 20 questions" (no source, filter "All"). With the source "All questions"
  and a filter it reads e.g. "Start drill · 9 not seen yet".
- The Home study-bank tile's button opens `#/drill?source=bank&filter=unseen` (bank only, not seen yet).
- The results screen's "Drill this section" for an origin section opens `#/drill?source=bank`.

## Code
- `src/engine/select.ts`: `DrillSource` (`'all' | 'bank'`) and `DrillOptions.source`. `drillPool` applies the source,
  then the filter. The v2.3.0 filter value `'bank'` stays as an alias of source bank + filter all, so older
  links and callers keep working. This module is not part of `@study/pack/engine`, so there is no contract
  change and nothing for the content repo to do (the pinned tag in the README moves to v2.3.1 with the release).
- `src/ui/screens/DrillSetup.tsx`, `Dashboard.tsx`, `MockResults.tsx`.
